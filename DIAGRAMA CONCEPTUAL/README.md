Explicación del diagrama

La figura muestra el esquema semántico desarrollado para estructurar el KG utilizado en este trabajo.
Basado en la arquitectura RDF (tripletas Sujeto–Predicado–Objeto), el modelo permite describir las
entidades biomédicas y sus relaciones de forma interoperable.
Dicho modelo semántico se organiza en cinco dominios principales: “chemical entity”, “pathway”, “gene”, “protein” y “disease”, representados mediante nodos de color verde. El flujo biológico de la red comienza en la entidad química, que engloba tanto a los fármacos antitumorales como a los agentes dopantes. Para garantizar su integración desde múltiples repositorios heterogéneos, cada compuesto se conecta con atributos literales en nodos morados y, además, se vinculan a bases externas mediante propiedades de equivalencia semántica (owl:sameAs), asegurando una interoperabilidad robusta.
Una entidad química actúa sobre un gen específico, el cual codifica una proteína determinada. Dicho gen, a su vez, se relaciona con el desarrollo de un fenotipo concreto. Para otorgar un contexto sistémico a estas interacciones, el modelo añade las rutas biológicas afectadas (pathways), que se conectan jerárquicamente tanto con los genes como con las enfermedades, permitiendo rastrear cómo la alteración molecular inducida por un fármaco afecta en cada dominio del mapa metabólico. 
Para capturar la complejidad real de la biología, las conexiones entre estos dominios no son estrictamente directas, sino que se introducen nodos de asociación, representados en color naranja (como chemical-gene association o gene-disease association), que actúan como puentes estructurales que representan las interacciones entre nodos. Esto permite enriquecer las relaciones agregando datos adicionales significativos, como el mecanismo de acción molecular. 
Finalmente, cada nodo de asociación se vincula de forma explícita a una evidencia documental (article) mediante la integración de identificadores de PubMed, toda interacción biológica de la red queda sólidamente respaldada por la literatura científica.
